# AI-Driven Development Guideline

## Philosophy

- Small changes
- Frequent PR
- Deterministic builds
- CI as gatekeeper
- Documentation is part of the product

---

## Workflow

PLAN → IMPLEMENT → TEST → DOCUMENT → PR → CI → MERGE → RELEASE

---

## Naming Convention

feat:
fix:
docs:
chore:
refactor:
test:

---

## Safety Principles

- Never tag non-main branches
- Never skip CI
- Never implement without updating PLAN
